Google Search Console & SEO

Verifikasi kepemilikan situs di Google Search Console untuk memastikan indeks halaman lancar.

Masukkan kode dari meta tag <meta name="google-site-verification" content="KODE">.
Digunakan untuk tag Canonical dan Sitemap XML.

Google AdSense Monetisasi

Atur ID AdSense dan slot unit iklan yang tampil di atas, tengah, samping, dan bawah halaman.

Format harus diawali dengan ca-pub-.

Panduan Cepat Verifikasi Google

1. Langkah Google Search Console:

  1. Buka Google Search Console dan tambahkan URL domain.
  2. Pilih metode verifikasi Tag HTML atau File HTML.
  3. Jika memilih Tag HTML, salin kode isi content="..." lalu tempel di form di atas dan klik Simpan.
  4. Kirim URL sitemap: https://www.info-umkm.my.id/sitemap.xml di menu Sitemaps.

2. Langkah Google AdSense:

  1. Buka Google AdSense dan daftarkan situs Anda.
  2. Salin Publisher ID Anda (format ca-pub-xxxxxxxx) ke input AdSense di atas.
  3. Sistem otomatis membuat file ads.txt resmi di /ads.txt dan meta verification.
  4. Klik tombol Minta Peninjauan di dashboard AdSense Anda.
